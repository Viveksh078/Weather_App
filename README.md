# Weather_App

This is a simple Weather App built using HTML, CSS, and JavaScript. It allows users to check the current weather of any city by entering the city name. The app fetches real-time weather data using the OpenWeatherMap API and displays useful information such as temperature, humidity, wind speed, and the overall weather condition.

To build this project, you need basic knowledge of HTML for structure, CSS for styling, and JavaScript for functionality. The weather data is accessed through an API call to OpenWeatherMap, which returns a JSON response containing the necessary weather details.

To run this app, you must first sign up at the OpenWeatherMap website and generate your free API key. After obtaining the key, open the JavaScript file in the project and replace the placeholder text where the API key is required. Once that's done, simply open the index.html file in your browser and use the input field to search for the weather in any city.

This project is structured with three main files: index.html for markup, style.css for styling, and script.js for the logic. It is a beginner-friendly project that helps understand how to use APIs, handle user input, and dynamically update content using JavaScript.

This weather app is responsive and works on both desktop and mobile browsers. It can be further enhanced by adding features such as a 5-day forecast, error handling for invalid cities, or the ability to detect the user’s current location using the Geolocation API.

The project is open-source and can be modified or improved freely. It is a great exercise for learning frontend development and working with real-time APIs.
